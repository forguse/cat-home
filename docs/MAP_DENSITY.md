# 柳溪村地图密度设计

修订 3 将景物聚拢成林地、院落、岩坡和街沿。现有 192×128 格不扩张。724×540 的正常近景一次约见 15×11 格，因此以步行经过的画面来安排构图。修订 2 分布了 564 件景物，其中许多集中在南部林地，北邻里屋后、溪谷沿岸、公共地外围、东部入口和待建地之间仍有连续裸露的草面。

## 布局

坐标以左上角为原点，范围包含两端。表中坐标表示布置范围，正式道路、门前入口、生产地和站位的保护优先。林带在路旁成片聚合，局部排开两三个相邻树冠，朝空地稀疏过渡。屋后能紧凑，正门前需要让人、门和手上货物同屏可见。

## 景物、通行与镜头

- 布置主体为树、岩块、篱笆、灌木、木料堆、长椅及货箱。低草、花和芦苇作为过渡与地貌颜色，不能构成区域密集度的主要来源。各组固定位置由明确轮廓限定，散点只在范围内部有稳定排序。同一运行不会随机长出新树或改道路。
- 沿主路的代表画面须至少读出两个相邻景物群、该地区的活动点或前景收边。森林核心尽量形成连续树冠，矿场读出裸岩脊，居民区读出至少一个真正的院角，市场读出摊后院与空着的两格交通道。保留空白有用途，如水面、在作的田面、场上运动、卸货、汇车和未来项目地块。
- 实测使用 724×540 原生近景，也检查低角度冠层重叠。先对家门、主桥东西头、市场两端、北巷、东邻里、藏在林里的工作点、矿路、村口和远期区取景。树冠与地面脚点分别审核，避免前景遮住相邻可用门、排队或人物上半身。最大尺度仍以季节更替与夜间光源判读。
- 固定景物绝不占用编译道路/支路、建物和正式地块、生产作物、桥面、所有 POI 与室外交互入口、水和钓位、动态生产树及工作脚点。运行里还有未完全转成蓝图的路线、拾放站、两人相遇站与动物轨迹。作者工具为这些本地坐标留空间，避免给动态寻路加隐形站点阻塞。
- `temporary_ground` 指仍可步行的荒草和芦苇。布置范围包括未开垦田床、六个远期建设地块、尚未铺设的 `future_lane`，以及集市、东街、公共会堂和三处兼容住宅的未开工足印。编译器只给这些足印开放草穗，通用道路、站位和装卸口继续排除。耕作、房屋开始清场、公共工程开工、建筑启用或草面变成道路后，按当下实际状态隐藏足印内的草。临时草不改变地籍、库存或步行。
- 旧住宅的 (6,4)、(18,5)、(35,32) 三处地籍同时检验门前脚点和施工美术范围。树、岩石、木堆等依据其从脚点向上的最大遮挡包络与建筑深度比较。固定景物靠侧面或后面聚合，留出完整前景。

## 修订与验收

1. 原蓝图中的建筑、道路、水、门、物件资料和地块保持原 ID 与原坐标。新增景物统一有修订命名前缀，生成器使用固定命名、排序和条件。原蓝图是 `assets/maps/willow-village-192x128-r1.json`，地图 ID 不随修订改变，`map_revision` 由 2 增至 3。Rust 和二进制资源由现有编译器生成。
2. 校验旧、新版本无既有碰撞删除或移动，新增实体不能造成原可行陆地被围成孤岛。除桥的阶段通行外，主干及长度样本保持不变。编译原 31 个阶段组合，并在 `map_dense_r3` 启用后逐一再验，共 62 组。填满六块未来工程和篮球场后仍能走到其他公共站点。关闭 `map_dense_r3` 时逐格比较原地形、道路、桥面、碰撞及所在地区，保持修订 2 的几何。记录每区地物、结构物占比、净新增碰撞、陆路审计数量，与图像同时验收。
3. 兼容由宿主识别旧碰撞版本。保留实体当前位置、活动所有权和在途货物。旧档角色正站在新增障碍、目标被挡或在途的情况单独验收。避免新版本只因更改景物而丢弃一笔已付工程、施工材料、村民在途物、原家门和共同活动。
4. 独立取景读同一份正式地图。待测包含实际开市的周六、四摊结束后、南桥落成、现有工程和晚期南田。性能验收量实际屏内空间索引和绘制开销，地图总件数只用于核实存储及复现。

当前蓝图保留原 564 件景物，增加 3,231 件，其中 2,356 件会改变步行碰撞、732 件属于可踏过的临时草甸。44 组地表颜色与足印内的荒草是两套绘制信息。编译后的地形表仍为 49,152 字节，62 个阶段组合检查道路、门位与互动站。
