# 柳溪村密植显示补充

树、岩块、矮篱和院落沿用地图中已有的格位、阶段和可行走性。树林成片时保留冠层，路口、树下作业位、房门及走过街道的两位主角需要仍能辨认。

## 地物与视口

- 景物选用的图集、翻转、缩放和脚点偏移在绘制与索引之间共用。索引以真实画幅和地影的并集登记到相交地图块。窗口移动后查询相交块，去重、再查画幅，并沿用脚点深度顺序。树根在视口外、冠层伸入画面时仍绘制冠层。3840×2160 测试视口内有超过 512 件景物，分块查询和逐件画幅比对的结果一致。静态景物独立于动态绘制项的 512 件上限。
- 地物只在其地图阶段开放时绘制。新地图阶段沿用运行时授权，旧档迁移期间的可见地物仍遵从同一掩码。池塘、农田、摊位和未来地籍各自遵循已发布用途及坐标。
- 集市优先显示已开放的摊位铺装、正在施工的道路和公用通行面。其余草地的地被与北缘、仓侧及背巷景物呼应。地图给出地被的中心、范围和主色，渲染用静态起伏打散边缘，并从草地、碎石和裸土材质提取细节。未开发地的草簇和干芦苇皆可踩过。实际除草后退出对应田块，摊位启用后退出整块地基和台阶，施工开始后退出正在使用的摊位或房屋足印。道路开通后清除其上的临时草。作物、货物和施工材料来自既有活动与库存。

## 树冠与人物

- 固定阔叶树、经营林和各期果树用同样的遮挡检查。只有在脚点确实靠画面后方、人物与冠层有效像素相交时，才局部减弱遮挡。选择所有可见且醒着的主角，包含在树下站定或工作的人。
- 冠层以原有脚点和材质绘制。主角轮廓附近降低不透明度，边缘逐渐过渡，其余树冠、树根与接地影保留。多棵前景树重叠时同样让出人物所在区域。较低的灌木、树篱、岩块保留原有深度。

## 验证结果

41 项显示测试通过。覆核了奇数视口、跨块画幅、超大窗口、滚动地表缓存、密植林冠前站定的主角，以及除草、工地清理和启用摊位后的临时草退场。原有单人屋和双人屋各 6 个阶段沿用可见画幅比较门槛，全部通过。

修订 3 新档和第 730 日成熟快照各取 20 个相同的 724×540 机位。两批取景涵盖院地、池边、田、果园、经营林、主桥、溪谷、北邻里、市场、工坊、东邻里、公共地、南田、采石区、东林、湿地、远期地块、北接线和东入口。40 帧均未发现整屏单调草地。第 730 日图为迁移后存档同机位取景，显示的是该时刻的状态。[新档总览](media/map-density-fresh-1.1.3.png) · [成熟总览](media/map-density-mature-1.1.3.png) · [局部对照](media/map-density-stages-1.1.3.png)
