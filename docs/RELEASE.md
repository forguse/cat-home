# 柳溪村 1.1.12

- GitHub 仓库和 Windows 下载文件统一使用 `liuxi-village`。
- 同目录首次运行新版会接续已为旧版开启的登录启动。存档仍从原目录读取。
- 村民和访客的姓名牌采用 Noto Sans SC 2.004。字体版权与 SIL Open Font License 1.1 已随发布提供。
- EXE 内置完整的第三方许可与鸣谢。右键 → 关于柳溪村 → 第三方许可与鸣谢可查看同一份文本。
- 本页附带 `THIRD_PARTY_NOTICES.txt`，可单独查阅或随 EXE 转发。下载附带的 `SHA256SUMS.txt` 可校验 EXE。

下载 `liuxi-village-windows-x64.exe` 后双击运行。升级时先退出旧版，把新版 EXE 放进原目录再打开。
