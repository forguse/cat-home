# 猫咪小屋 1.1.8 · 条件变体

新增 88 个条件变体。正式村庄现有 100 个基础行为和 168 个变体，旧目录还余 4,408 个变体。

- 试井、看新设施、歇脚、排涝和回屋休息后，按当次时段、天气和位置留下可查看的记录。右键「观察手记」能看到当前有效的记录及剩余时间。
- 实际倒树后，靠近的角色会退开，落点的提示按场景保留 5、15 或 30 个世界分钟。
- 画家把同一块画板带回挂起，满足条件时会留展至少 14 或 28 个世界日。
- 厨师只为实际备好的餐食开放菜单。燕子春归时重访以前筑成的同一座巢。

记录使用 12 个固定槽，画家使用原有的四块画板。升级保留进度、窗口和原存档备份。

下载 cat-home-windows-x64.exe 后双击即可直接运行。已有 1.1.7 用户请退出旧版，再在原目录替换 EXE。
