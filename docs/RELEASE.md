柳溪村是一个可以放在 Windows 桌面上观察的小型像素世界。1.1.6 新增 22 项有实际来源、过程和结果的基础行为。

- 旧 5,000 条目录累计接入 46 项基础、41 个条件变体，共 87 个编号；其余 4,913 个尚未接入。这不是 87 套独立动画。
- 两块回收田收后重新整地；分拣真实收成并留种；干田分三次使用同一桶水；真实受淹田由主角或水工现场排涝。
- 厨师把实际菜皮运到堆肥桶，经过混叶、翻堆、熟化再施田；给同一有效预约的来客送一份真实饭，取消则带回原份。
- 米信把同一封原信交到主角手里，木匠携真实定尺件修粮架，谷芽为实际买家保留最后一袋种子。
- 橘子闻饭后吃饭、饭后室外午睡、天黑走回家、试探初雪；麻雀黎明落檐，小鸭在雨后湿岸留下会消退的脚印。
- 蜜蜂实际访问两株开花树，目标树下一批成熟果量最多加一。取消了旧天气散列的无访问增产；不会直接向库存发水果。
- 主角先回屋换衣，再进行雨中田务或门廊饮水休息。两人窄路互让，继续完成原任务，保留货物和真实路线。
- 修复已用水错误退满桶、新田施肥后的存档校验、满堆肥桶的继续处理，以及晒粮被普通加餐挤占。成熟邻居从附近已开放合作田取菜回家做饭，章节完成后继续保留这条合理日常。
- 观察手记显示真实角色、世界日和行为。原地图、景物顺序、已清地物、建设、窗口尺寸、启动和退出入口保留。

下载 `cat-home-windows-x64.exe`，放进可写文件夹后双击。更新时先退出旧版、替换 EXE，保留 `home-data-v2` 和位置文件；首次升级会归档原行为修订存档。附件 `SHA256SUMS.txt` 用于核对下载文件。

所有新增任务、物资包、预约、动物记忆和授粉状态均有数量上限。已见记录使用固定 768 字节位图和最多 12 条近期记录，存档上限 256 KiB，不按运行天数追加图片或永久事件文件。保存不再复制整份世界和居民数据。画外继续模拟，仅绘制与视野相交的内容。

新增行为中 21 项有自主回放证据；主角排涝分支目前由专项测试验证，不能把水工排涝当作该分支的自然证据。程序复用现有走路、持物、工作、换装和睡眠图集，补充有限道具与过程视觉，并未逐项重绘专属动画。

验证通过 254 项库测试、70 项 Windows 测试、20 项地图测试和 4 项登记边界测试。2,000 世界日回放完成 23 项社会进度；终版新档 60 小时、玩家副本 24 小时、成熟副本 48 小时均保存重开一致。这些是模拟和副本验证，不是实际挂载两年或保证每个存档在同一时刻触发相同行为。
