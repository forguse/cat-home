# 猫咪小屋 1.1.9 · 柳溪村

本版接入 126 条条件变体。柳溪村累计有 100 类基础行为和 294 条精确变体。

- 两人确实让路并走到原目标，或因空餐柜改道并完成做饭后，才会在走过的地面留下痕迹。
- 清理地块后，等收集到的物料实际归仓，原地才会留下提示。
- 新增阴云散开、倒木避让、屋檐避雨、清晨鸟鸣和池边下竿的限时场景。秋晨燕雀互动会等两只鸟停在各自的真实位置。
- 右键打开「观察手记」可以查看现场记录和剩余时间。现有存档升级后会保留进度，并保存升级前副本。
